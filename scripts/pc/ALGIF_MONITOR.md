# algif_monitor — мониторинг офлайн машин

Запускается после `fix_algif`. Висит в фоне и автоматически применяет
фикс к машинам как только они появляются в сети.

---

## Установка

```bash
cp algif_monitor.sh ~/.local/bin/algif_monitor
chmod +x ~/.local/bin/algif_monitor
```

Поменяй логин админа в скрипте (строка 14):
```bash
ADMIN_USER="admin"  # ← твой реальный логин
```

---

## Рабочий процесс

```bash
# 1. Сначала прогоняешь основной скрипт
fix_algif

# 2. Сразу запускаешь мониторинг для офлайн машин
algif_monitor

# 3. Проверяешь статус в любой момент
algif_monitor --status
```

Мониторинг работает в фоне — можно закрыть терминал, он продолжит работу.

---

## Команды

```
algif_monitor            — запустить мониторинг в фоне
algif_monitor --status   — показать кто обработан, кто ждёт
algif_monitor --stop     — остановить мониторинг
```

## Где хранятся логи

```
~/.config/pc/algif/
├── done.log        — обработанные машины (ip, сотрудник, время)
├── pending.log     — ожидают обработки (ip, сотрудник)
└── monitor.log     — подробный лог всех событий
```

По `done.log` можно отчитаться руководству.

---

## Остановка

Мониторинг останавливается автоматически когда все машины обработаны.
Или вручную:

```bash
algif_monitor --stop
```
