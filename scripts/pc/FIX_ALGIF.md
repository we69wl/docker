# fix_algif — массовое устранение уязвимости algif_aead

Скрипт автоматически подключается по SSH ко всем Linux-машинам из базы `pc`
и блокирует загрузку уязвимого модуля ядра `algif_aead`.

---

## Что делает скрипт на каждой машине

```bash
# Блокирует модуль через modprobe
echo "install algif_aead /bin/false" > /etc/modprobe.d/disable-algif.conf

# Выгружает модуль если сейчас загружен
rmmod algif_aead 2>/dev/null
```

Это временная мера — до установки обновления ядра.

---

## Перед запуском

**1. Поменяй логин админа в скрипте** (строка 11):
```bash
ADMIN_USER="admin"  # ← поставь свой реальный логин
```

**2. Проверь есть ли sshpass:**
```bash
which sshpass
```

Если нет — установи:
```bash
sudo apt install sshpass
```

Если sshpass недоступен — скрипт попробует подключиться без пароля.
Машины где не получится будут помечены как `нет доступа`.

**3. Проверь на одной машине вручную** перед массовым запуском:
```bash
ssh admin@192.168.111.X "sudo -n echo ok"
```

---

## Установка

```bash
cp fix_algif.sh ~/.local/bin/fix_algif
chmod +x ~/.local/bin/fix_algif
```

---

## Запуск

```bash
fix_algif
```

Скрипт попросит мастер-пароль от базы `pc`, затем пройдёт по всем машинам.

## Лог

После каждого запуска сохраняется лог:
```
~/.config/pc/fix_algif_ДАТА_ВРЕМЯ.log
```

По нему можно отчитаться руководству какие машины обработаны.

---

## Машины которые были офлайн

Когда сотрудник появится на рабочем месте — запусти скрипт повторно,
он пропустит уже обработанные машины и дойдёт до офлайновых.

Или вручную на конкретной машине:
```bash
ssh admin@IP "sudo bash -c 'echo install algif_aead /bin/false > /etc/modprobe.d/disable-algif.conf && rmmod algif_aead 2>/dev/null; echo OK'"
```

---

## Windows-машины

Скрипт их просто пропускает — ping не ответит или SSH недоступен,
статус будет `офлайн`. На Windows модуль `algif_aead` не существует,
там уязвимость неприменима.
