# passgen — генератор паролей для сотрудников

Скрипт для генерации, хранения и отслеживания паролей от доменных учёток.
Пароли хранятся в отдельном зашифрованном GPG файле.

---

## Требования к паролям

- Длина: **15 символов**
- Обязательно: заглавные буквы, строчные буквы, цифры, спецсимволы (`!@#$%^&*()_+=`)
- Смена: каждые **40 дней**

---

## Установка

```bash
cp passgen.sh ~/.local/bin/passgen
chmod +x ~/.local/bin/passgen
```

Зависимости (всё уже есть в Astra Linux):
- `gpg` — шифрование
- `python3` — генерация паролей
- `fzf` — интерактивное меню (бинарник из папки `pc/`)

---

## Первый запуск

```bash
passgen
```

Скрипт создаст пустую базу и попросит придумать мастер-пароль.
После этого незашифрованный файл удаляется — на диске остаётся только `passwords.csv.gpg`.

> Мастер-пароль нигде не хранится. Если забудешь — базу придётся заполнять заново.

---

## Команды

```
passgen              — список всех сотрудников и статус паролей
passgen --new        — выдать новый пароль сотруднику
passgen --show       — найти и показать пароль
passgen --edit       — редактировать базу вручную
```

---

## Как выдать пароль сотруднику

```bash
passgen --new
```

1. Выбери сотрудника из списка или введи имя нового
2. Скрипт сгенерирует пароль и покажет на экране
3. Сотрудник записывает пароль
4. Нажми Enter — пароль сохранится в зашифрованную базу

---

## Главный экран

```bash
passgen
```

Показывает всех сотрудников и статус:

```
  Сотрудник                 Выдан        Сменить до   Статус
  ─────────────────────────────────────────────────
  Иванов Иван               2024-04-12   2024-05-22   ● просрочен
  Петрова Мария             2024-05-10   2024-06-19   ● 4 дн.
  Сидоров Алексей           2024-05-15   2024-06-24   ● ok
```

- `● ok` — всё в порядке
- `● N дн.` — осталось меньше 7 дней, пора предупредить сотрудника
- `● просрочен` — пароль нужно сменить

---

## Где хранится база

```
~/.config/pc/passwords.csv.gpg
```

Тот же каталог что и база `pc`, но отдельный файл с отдельным мастер-паролем.

Права доступа выставляются автоматически (`chmod 600`).
