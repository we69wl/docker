# Установка команды `pc` с GPG-шифрованием

## 1. Скопируй файлы с флешки

```bash
# fzf — кладёшь бинарник
sudo cp fzf /usr/local/bin/
sudo chmod +x /usr/local/bin/fzf

# Скрипт pc
mkdir -p ~/.local/bin
cp pc.sh ~/.local/bin/pc
chmod +x ~/.local/bin/pc
```

Проверь PATH:
```bash
echo $PATH | grep -q ".local/bin" && echo "OK" || (echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc && source ~/.bashrc)
```

---

## 2. Проверь что gpg есть (обычно уже стоит в Astra)

```bash
gpg --version
```

Если нет: `sudo apt install gnupg`

---

## 3. Первый запуск — создать базу

```bash
pc
```

Скрипт создаст пустой файл `~/.config/pc/computers.csv` и объяснит что делать дальше.

---

## 4. Заполни базу

```bash
nano ~/.config/pc/computers.csv
```

Формат (первая строка — заголовок, не трогать):
```
employee,ip,password
Иванов Иван,192.168.111.5,Admin@2024
Петрова Мария,192.168.121.12,Qwerty123!
Сидоров Алексей,192.168.111.23,P@ssw0rd
```

---

## 5. Зашифруй базу

```bash
pc --encrypt
```

Введёшь мастер-пароль дважды — запомни его, без него база недоступна.
После этого `computers.csv` будет удалён, останется только `computers.csv.gpg`.

---

## 6. Запуск

```bash
pc
```

При первом запуске за сессию gpg спросит мастер-пароль.
Следующие 4 часа — без запроса (gpg-agent кэширует).

---

## Добавить / изменить запись

```bash
pc --edit
```

Откроет расшифрованный файл в nano, после сохранения сразу зашифрует обратно.
Незашифрованный файл на диске не остаётся.

---

## Что защищает шифрование

| Угроза | Без GPG | С GPG |
|--------|---------|-------|
| Кто-то открыл твой файловый менеджер | ❌ | ✅ |
| Украли ноутбук | ❌ | ✅ |
| Доступ к твоей учётке | ❌ | ✅ |
| Ты сам забыл мастер-пароль | ✅ | ❌ |

> Мастер-пароль нигде не хранится — только в твоей голове.
> Если забудешь — базу придётся заполнять заново.
